## 1. 프로젝트 개요

대한민국의 대표적인 온라인 패션 플랫폼인 무신사는 방대한 의류 데이터를 보유하고 있다. 이 데이터를 효과적으로 활용해 사용자 경험과 온라인 쇼핑의 편의성을 높이기 위해 의류 이미지 검색 서비스를 기획했다.

최근 Google과 네이버를 비롯한 주요 기술 기업이 이미지 검색 기능을 강화하면서 이미지 기반 검색 기술의 중요성이 커지고 있다. 이 프로젝트의 핵심 목표는 사용자가 텍스트 대신 사진으로 원하는 제품을 쉽고 빠르게 찾도록 하는 것이다. 외부 쇼핑 플랫폼이나 검색 서비스를 거치지 않고 무신사 앱에서 바로 상품을 검색할 수 있게 하면 플랫폼 체류 시간이 늘어나고, 상품 탐색부터 구매까지의 여정을 무신사 안에서 완결할 수 있다. 이는 고객 이탈률 감소와 매출 향상, 사용자 만족도 및 플랫폼 충성도 제고에 기여할 수 있다.

## 2. 프로젝트 모델링 과정

### 2.1. 데이터셋 구성

무신사 웹사이트에서 정형 데이터와 비정형 데이터를 수집한다.

- **정형 데이터:** 제품명, 가격, 브랜드, 카테고리, 소재, 색상 등을 수집한다. 모델 학습에 직접 사용하지 않더라도 후속 분석에 활용할 수 있다.
- **상품 이미지:** 각 상품의 대표 이미지를 수집한다.
- **리뷰 이미지:** 사용자 리뷰에 포함된 실제 착용 이미지와 사용자가 업로드한 이미지를 수집한다. 이는 모델의 일반화 성능을 높이는 데 중요한 데이터가 된다.

프로젝트의 효율성과 집중도를 높이기 위해 의류 전체를 한 번에 다루기보다 상의, 하의, 모자 등 특정 카테고리를 중심 분야로 정하는 방안을 고려했다. 선택한 카테고리에 집중하면 더 정교한 모델을 개발할 수 있다. 실제 프로젝트에서는 상의를 대상으로 실험을 진행했다.

### 2.2. 데이터 전처리

**데이터 라벨링:** OpenPose로 이미지 속 인체의 주요 지점을 감지하고 상의와 하의를 구분하는 기본 라벨을 만든다. 원하는 이미지 영역을 분리하는 알고리즘에도 활용할 수 있다. Detectron2와 같은 객체 탐지 모델을 사용하면 상의, 하의, 액세서리 등 세부 의류 항목을 자동으로 감지하고 라벨링할 수 있다. 기존에 연구된 의류 관련 모델을 함께 활용하여 라벨의 정확도를 높인다.

의류는 신체와 밀접하게 연관되어 있으므로 OpenPose 기반 라벨링이 효과적일 것으로 예상했다. 다른 딥러닝 모델도 함께 검토하여 다양한 접근법을 시도할 수 있다. 관련 참고 자료가 풍부해 라벨링 과정의 시행착오를 줄일 수 있으며, 라벨 데이터와 메타데이터를 연결해 이미지 설명을 JSON 형식으로 정리하면 검색과 분석도 효율적으로 수행할 수 있다.

**데이터 스케일링:** 이미지 데이터를 학습 가능한 크기로 변환하고 모든 이미지의 스케일을 동일하게 맞춘다. 필요하면 이진화와 흑백 변환을 적용해 불필요한 잡음을 제거하고 모델이 본질적인 특징에 집중하도록 한다.

**이미지 패딩:** 모든 이미지 크기를 동일하게 맞추기 위해 부족한 영역을 채운다. 이미지 경계가 모델 학습에 불필요한 영향을 주는 것을 줄이고, 입력 크기를 일정하게 유지하여 학습 효율을 높인다. 이 밖에도 여러 전처리 방식을 실험해 더 적합한 모델 입력을 구성한다.

### 2.3. 모델 후보 탐색

Hugging Face에서 제공하는 사전 학습 모델 중 이미지 객체 탐지와 분류에 적합한 모델을 찾았다. 주요 후보는 ResNet, Detectron, YOLO 등 CNN 기반 모델이다.

- **ResNet:** 깊은 레이어 구조에서도 이미지 특징을 효과적으로 학습할 수 있어 의류 이미지 분류에 적합하다.
- **Detectron:** Meta AI의 객체 탐지 및 인스턴스 분할 모델로, 상의와 하의 같은 세부 의류 카테고리를 분리하는 데 활용할 수 있다.
- **YOLO:** 이미지에서 의류 항목을 빠르게 탐지하고 분류할 수 있는 실시간 객체 탐지 모델이다.

수집한 라벨 데이터를 모델 학습에 사용하며, 데이터 품질을 지속적으로 검토한다. 필요한 경우 라벨을 수동으로 수정하거나 추가 라벨링을 수행해 정확도를 높인다. 각 모델이 요구하는 데이터 형식을 확인하고, 마지막 출력층을 프로젝트의 상품 분류 구조에 맞게 변경하는 방법도 함께 검토했다. 메타데이터 형식은 JSON을 고려했다.

## 3. 배경 지식 및 사전 조사

### 3.1. 컴퓨터 비전과 합성곱 신경망

컴퓨터 비전은 사람의 시각을 복제하는 데에만 국한되지 않는다. 사람이 수행하기에 지나치게 반복적이거나 시간이 많이 들고, 비용 또는 오류 발생 가능성이 큰 문제에도 적용할 수 있다.

합성곱은 데이터에서 특징을 추출하는 연산이다. 숫자로 구성된 행렬을 데이터 위로 이동시키며 데이터와 행렬 원소 간 곱의 합을 구한다. 이때 사용하는 행렬을 커널 또는 필터라고 한다. 이미지 증강과 임베딩 등 최종 전처리에는 TensorFlow와 Keras를 활용할 수 있고, 이미지 분류에는 ResNet과 YOLO 같은 CNN 기반 모델을 적용할 수 있다.

### 3.3. 과적합 방지를 위한 이미지 증강

기본 증강 방식으로 수평·수직 뒤집기, 회전, 이동, 확대 및 축소, 색상 변화, 회색조 변환, 채도 및 밝기 조절, 중앙 자르기, 크롭, 블러, 노이즈 등을 검토했다.

특수 증강 방식은 다음과 같다.

- **Random crop:** 이미지의 임의 영역을 잘라 학습에 사용한다.
- **Cutout:** 이미지에서 무작위로 정한 직사각형 영역을 0으로 채운 뒤 입력으로 사용한다.
- **CutMix:** 서로 다른 이미지를 겹쳐 모델이 이미지의 덜 두드러진 영역에도 집중하도록 한다.

이러한 증강은 과적합을 줄이고 모델을 안정적으로 학습하는 데 도움이 된다. 증강 방식을 자동으로 최적화하는 adaptive augmentation도 검토했다.

- **AutoAugment**
- **RandAugment:** AutoAugment를 단순화한 방식
- **TrivialAugment:** 데이터 분포를 크게 왜곡하지 않으면서 간단한 이미지 증강을 적용하는 방식

### 3.5. ResNet

일반적인 깊은 신경망에서는 층이 깊어질수록 기울기가 작아져 가중치가 제대로 갱신되지 않는 기울기 소실 문제가 발생할 수 있다. ResNet은 이를 해결하기 위해 스킵 연결을 사용한다. 여기서 스킵은 학습을 생략한다는 의미가 아니라 이전 층의 입력을 다음 층으로 직접 전달한다는 의미다.

일반적인 신경망의 각 층은 새로운 특징 전체를 학습해야 하지만, ResNet의 레이어는 이전 결과를 전달받아 그 차이인 잔차만 학습한다. 입력을 `x`, 학습할 변환을 `F(x)`라고 하면 출력에 `x`를 더해 `F(x) + x`를 만든다. 레이어가 작은 정보만 추가로 학습하므로 학습량이 줄고, 깊은 신경망도 효과적으로 최적화할 수 있다. 이 구조는 복잡한 이미지 분류 작업에서 좋은 성능을 보인다.

## 4. 모델 설계 및 전이 학습

프로젝트에서는 무신사 이미지 검색 기능을 구현하기 위해 ResNet-18과 ResNet-50을 사용했다. 두 모델 모두 ImageNet으로 사전 학습된 가중치를 불러오고, 특징 추출을 담당하는 기존 레이어는 동결했다. 프로젝트의 상품 분류 문제에 맞게 완전 연결층과 Dense layer, 출력층만 교체하여 학습했다.

- **Fully Connected Layer / Dense Layer:** 이미지에서 추출한 전체 특징을 바탕으로 중요한 패턴을 학습하고 최종 결정을 내린다.
- **Output Layer:** 입력 이미지가 어느 클래스에 속하는지 예측 결과를 출력한다.

| 구분 | ResNet-18 | ResNet-50 |
| --- | --- | --- |
| 레이어 수 | 18개 | 50개 |
| 모델 규모 | 상대적으로 작음 | 상대적으로 큼 |
| 장점 | 계산 비용이 적고 학습이 빠름 | 더 높은 성능을 기대할 수 있음 |
| 고려 사항 | 표현력에 한계가 있을 수 있음 | 더 많은 계산 자원이 필요함 |

[ResNet 비교 참고 자료](https://wikidocs.net/192928)

### 4.1. ResNet-18 설정

합성곱 레이어와 배치 정규화 레이어의 활성화 함수로 ReLU를 사용했다. ReLU는 입력이 0보다 크면 값을 그대로 출력하고, 0보다 작으면 0을 출력하는 대표적인 활성화 함수다.

출력층에는 여러 클래스 중 하나를 선택하는 문제에 적합한 Softmax를 적용했다. Softmax는 입력값을 확률로 변환하여 각 클래스에 속할 확률을 출력한다. 가중치를 갱신하는 옵티마이저로는 손실을 줄이는 방향으로 조금씩 값을 조정하는 SGD를 사용했다. 정확도 측면의 한계는 있지만 빠르게 학습할 수 있다는 점을 고려했다. 손실 함수에는 예측 확률 분포와 실제 데이터 분포의 차이를 측정하는 Cross-Entropy Loss를 사용했다.

### 4.2. ResNet-50 설정

활성화 함수는 ResNet-18과 동일하게 구성했다. 옵티마이저에는 학습 속도를 높이고 복잡한 모델을 안정적으로 학습할 수 있는 Adam을 사용했으며, 손실 함수에는 다중 클래스 분류에 특화된 Categorical Cross-Entropy를 사용했다.

입력층의 가중치를 동결하고 완전 연결층에는 ReLU를 적용했다. 학습 과정에서 일부 뉴런을 무작위로 비활성화하는 Dropout으로 과적합을 방지했으며, 출력층에서는 Softmax로 상품이 각 카테고리에 속할 확률을 계산했다. 훈련 데이터와 검증 데이터는 8:2로 나누었다. 과적합을 줄이고 기존 전이 학습 연구의 설정을 참고해 배치 크기는 32로 지정했다. 컴퓨팅 자원의 한계로 학습은 20 epoch까지만 진행했다.

## 5. 실험 결과

### 5.1. 상품 100종 분류

학습 그래프에서 파란색은 훈련 정확도와 손실값, 빨간색은 검증 정확도와 손실값을 나타낸다. 상품 수는 100종이지만 상품당 학습 이미지가 약 200장으로 부족해 모델 정확도가 낮게 나타났다.

### 5.2. 상품 1,000종 분류

파란색은 훈련 정확도와 손실값, 빨간색은 검증 정확도와 손실값이다. 상품 수가 1,000종으로 많은 데 비해 상품당 학습 데이터가 약 200장에 불과하여 정확도가 낮고 손실값이 매우 높게 나타났다.

### 5.3. 상품 500종 분류

상품 수가 500종인 실험도 상품당 학습 데이터가 부족했다. 그 결과 6 epoch 이후부터는 학습이 거의 진행되지 않았다.

## 6. 한계 및 기대 효과

### 6.1. 프로젝트의 한계

컴퓨팅 자원이 부족해 모델을 충분히 학습하지 못했고 결과도 기대에 미치지 못했다. 이미지 데이터의 다양성 역시 정확한 결과 도출을 어렵게 했다. 같은 상품 안에도 서로 다른 색상의 의류 이미지가 포함되어 있어 학습된 모델의 정확도가 낮아졌다.

> 초기 모델 학습에 필요한 대규모 데이터와 충분한 컴퓨팅 자원이 필요하다.

### 6.2. 기대 효과

1. 데이터셋을 안정적으로 구축하고 이미지 증강을 적절히 적용하면 적은 원본 데이터로도 정확도를 높여 브랜드가 제공하는 데이터 수준의 검색 모델을 학습할 수 있다. 이는 고객 만족도 향상으로 이어질 수 있다.
2. 사용자가 옷 이미지 검색을 위해 무신사 앱을 벗어나지 않아도 되므로 외부 플랫폼 의존도와 고객 이탈률이 줄고, 매출 증가를 기대할 수 있다.
3. Google Lens는 쇼핑만을 위해 구축된 서비스가 아니므로 검색 결과 이미지가 반드시 구매 링크로 이어지지 않으며, 검색 카테고리나 이미지 특징 추출 기준을 세밀하게 선택하기 어렵다. 무신사 전용 이미지 검색 서비스는 이러한 한계를 보완할 수 있다.

## 7. 발전 방향

1. 상품 데이터를 지속적으로 추가하고 모델을 재학습하여 이미지 검색 성능을 개선한다.
2. 이번 프로젝트에서 다룬 상의뿐 아니라 다양한 의류 카테고리로 서비스 범위를 넓혀 여러 고객 요구를 충족한다.
3. 사용자 맞춤형 추천 시스템과 연계하여 취향에 맞는 옷을 추가로 제안하고 부가적인 매출을 만든다.
4. 제품 이미지를 상품명으로만 구분하지 않고 색상 등 세부 조건에 따라 분류하여 더 정확한 검색 결과를 제공한다.

## 8. 발표 구성안

발표는 데이터 전처리 설명에 이어 다음 순서로 구성한다.

1. 모델 선택 과정: 회귀 모델과 ResNet 검토
2. ResNet의 기본 개념과 스킵 연결
3. ResNet-18과 ResNet-50 비교
4. 전이 학습 설정: 완전 연결층, Dense layer, 출력층 교체 및 나머지 레이어 동결
5. 실험 결과
6. 프로젝트의 한계
7. 의의와 향후 발전 방향
8. 참고문헌
9. 질의응답 및 마무리

발표 자료에서는 ResNet의 개념을 한 장으로 설명하고, ResNet-18과 ResNet-50의 공통점과 차이점을 표로 제시한다. 두 모델은 완전 연결층, Dense layer, 출력층만 교체하고 나머지 레이어를 ImageNet 사전 학습 가중치로 동결했다. 세부 차이에는 레이어와 노드 수, 계산 비용, 기대 성능을 포함한다.
