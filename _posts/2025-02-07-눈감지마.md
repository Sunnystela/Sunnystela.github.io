## **1. 프로젝트 개요**

### **1.1. 프로젝트 배경**

행사나 졸업식처럼 많은 사람과 함께 사진을 촬영하면 누군가는 눈을 감거나 반쯤 감긴 상태로 찍히는 경우가 종종 발생한다. 중요한 순간이나 한정된 시간에 단체 사진을 촬영할 때는 매번 결과를 확인하기 어렵고, 눈을 감은 사람이 있으면 재촬영해야 하는 번거로움도 생긴다.

사진 촬영 시 사람들의 눈 감김을 실시간으로 감지하고 즉시 알림을 제공하면 촬영 효율을 높이고 재촬영의 불편을 줄일 수 있다. 한 명의 눈 상태를 감지하는 기존 서비스와 달리, 이 프로젝트에서는 여러 명이 함께 찍는 단체 사진에서도 모두가 눈을 뜬 순간을 포착할 수 있는 개선된 서비스를 개발하고자 한다.

### **1.2. 목표 및 방향**

단체 사진 촬영 시 여러 사용자의 눈 감김 상태를 실시간으로 감지하여 촬영의 정확성과 편의성을 높이는 것이 목표다. YOLO 기반 객체 탐지 모델로 얼굴과 눈을 빠르게 인식하고, MobileNet 기반 눈 상태 분류 모델로 눈을 감았는지 실시간으로 판단한다. 필요하면 LSTM 기반 시계열 분석 모델을 결합하여 눈 감김 상태가 일정 시간 이상 지속될 때 즉시 알림을 제공한다.

초기에는 YOLO, MobileNet, LSTM을 결합하는 방향을 계획했지만, 실제 구현 과정에서는 dlib으로 얼굴 랜드마크와 눈 좌표를 검출하고 ResNet, MobileNet, 기본 CNN의 눈 상태 분류 성능을 비교했다. 이후 OpenCV와 분류 모델을 연결해 모든 사람이 눈을 뜬 시점을 판단하고 자동으로 사진을 촬영하는 흐름을 구현했다.

### **1.3. 프로젝트 구성**

- **활동:** KHUDA 6기 CV 트랙 심화 프로젝트
- **팀원:** 김민서, 김예람, 이하영, 장준필
- **진행 과정:** 논문 조사 → 데이터 전처리 → 모델링 → 애플리케이션 구현
- **최종 결과물:** 여러 사람의 눈 상태를 실시간으로 확인하고 사진을 자동 또는 수동으로 촬영할 수 있는 Streamlit 애플리케이션


## **2. 추진 계획**

### **2.1. 데이터셋 구성**

Closed Eyes in the Wild(CEW), CelebA Dataset, RLDD(Real-Life Drowsiness Dataset) 등 눈을 감은 상태와 뜬 상태가 모두 포함된 얼굴 이미지를 수집하여 데이터셋을 구축한다. 데이터가 부족하면 크롤링을 통해 이미지를 추가로 수집한다.

실제 실험에서는 눈 감김 여부에 대한 속성이 포함된 약 20만 장 규모의 CelebA 데이터셋을 중심으로 사용했다.

### **2.2. 데이터 전처리**

- **얼굴 및 눈 영역 추출:** OpenCV, YOLO, dlib을 사용한다. YOLO로 얼굴과 눈 영역을 추출한 뒤, 얼굴 랜드마크 검출기인 dlib으로 눈 좌표를 정확하게 파악하여 모델 학습에 필요한 데이터를 구성한다.

- **데이터 정규화 및 조정:** 이미지 크기와 비율을 일관되게 조정하여 모델이 동일한 형식의 입력 데이터를 학습하도록 한다.

- **라벨링:** 눈을 감은 상태와 뜬 상태를 구분하여 데이터에 라벨을 지정한다.

- **데이터 증강:** 데이터셋에 부족한 조명, 각도, 거리 변화를 반영할 수 있도록 다양한 이미지 증강 기법을 적용한다.

실제 전처리에서는 얼굴 이미지에서 눈 영역을 잘라낸 뒤 dlib의 얼굴 랜드마크를 이용해 눈 좌표를 구체화했다. 추출한 눈 이미지는 모델에 일관된 입력을 제공하도록 크기와 비율을 조정했다.

![alt](/assets/img/eye.fig1.png)


### **2.3. 모델 학습**

- **눈 감김 상태 분류:** MobileNet을 사용하여 눈 영역에서 눈 감김 상태를 감지하는 경량 모델을 학습한다. 수집한 데이터셋으로 모델을 학습하고 검증하여 감지 정확도를 최적화한다.

- **얼굴 및 눈 검출:** 얼굴과 눈을 빠르고 정확하게 실시간으로 검출할 수 있도록 YOLO 모델을 학습한다. 검출한 눈 영역은 MobileNet 분류 모델에 전달한다.

첫 번째 실험에서는 스마트폰 환경에서의 사용을 고려해 경량 네트워크인 MobileNet을 backbone으로 선택하고 ArcFace를 결합했다. ArcFace는 특징 벡터 사이에 각도 기반 마진을 두어 클래스 간 구분을 강화하는 손실 함수다. 그러나 이 구성은 기대한 성능을 내지 못했으며, 당시에는 하이퍼파라미터 설정이 원인일 가능성이 있다고 판단했다.

두 번째 실험에서는 기본 CNN, 사전 학습된 MobileNet, ResNet을 같은 눈 상태 분류 문제에 적용해 성능을 비교했다. MobileNet은 depthwise separable convolution을 통해 연산량을 줄이는 구조이고, ResNet은 residual connection을 사용해 깊은 네트워크의 학습을 안정화하는 구조다.

### **2.4. 모델 평가 및 검증**

- **성능 평가:** 눈 감김 상태의 분류 정확도와 YOLO의 얼굴 및 눈 검출 속도를 측정하여 실시간 감지 시스템으로서의 성능을 확인한다.

- **검증:** 다양한 조명, 각도, 환경에서 테스트하여 실제 사용 환경에서도 모델이 안정적으로 작동하는지 검증한다.

모델별 학습 정확도와 손실을 10 epoch 동안 비교했고, 별도의 테스트 세트에서 loss와 accuracy를 측정했다. 그 결과 ResNet이 세 모델 중 가장 낮은 테스트 손실과 가장 높은 정확도를 기록했다.

| 모델 | Test Loss | Test Accuracy |
| --- | ---: | ---: |
| **ResNet** | **0.0548** | **0.9778** |
| MobileNet | 0.5904 | 0.7253 |
| Basic CNN | 0.3140 | 0.8912 |

ResNet은 테스트 정확도 97.78%로 가장 좋은 결과를 보였고, 기본 CNN은 89.12%, MobileNet은 72.53%를 기록했다. 경량성을 이유로 MobileNet을 우선 고려했지만, 이번 데이터와 학습 설정에서는 모델 크기보다 분류 성능 측면에서 ResNet이 더 적합한 후보임을 확인했다.

### **2.5. 개발 도구 및 협업 방식**

- **협업 방식:** 대면 회의 및 Zoom 활용

- **개발 도구:** PyTorch, OpenCV, YOLO, Pillow, Scikit-learn 등

최종 애플리케이션은 Streamlit으로 구현했으며, 웹캠 영상 처리와 사진 저장에는 OpenCV를 사용했다. 얼굴과 눈 좌표 검출에는 dlib을 활용했다.


## **3. 시스템 구현**

### **3.1. 실시간 눈 상태 감지**

dlib의 얼굴 랜드마크 검출기를 이용해 프레임 속 각 얼굴과 눈의 위치를 찾고, 추출한 눈 영역을 분류 모델에 입력해 눈을 뜬 상태와 감은 상태를 구분했다. OpenCV는 웹캠 프레임을 받아오고, 감지 결과와 얼굴 영역을 화면에 표시하는 역할을 담당했다.

여러 사람이 화면에 들어오면 각 사람의 눈 상태를 개별적으로 확인한다. 화면 속 모든 사람이 눈을 뜬 것으로 판단되면 2초 동안 카운트다운한 뒤 사진을 자동으로 촬영하고 저장하도록 구현했다.



### **3.2. 전체 동작 흐름**

1. OpenCV로 웹캠 영상을 입력받는다.
2. dlib으로 프레임 안의 얼굴과 눈 좌표를 찾는다.
3. 각 눈 영역을 분류 모델에 입력해 눈의 상태를 판단한다.
4. 한 명이라도 눈을 감고 있으면 촬영을 대기한다.
5. 모든 사람이 눈을 뜬 상태가 되면 2초 카운트다운을 시작한다.
6. 카운트다운 이후 사진을 촬영하고 앨범에 저장한다.

### **3.3. Streamlit 애플리케이션**

모델을 실제로 사용할 수 있도록 Streamlit 기반의 애플리케이션을 제작했다. 애플리케이션은 자동 촬영, 수동 촬영, 앨범 확인 기능으로 구성된다.

- **자동 촬영:** 모든 사람이 눈을 뜬 순간을 감지하면 2초 후 자동으로 사진을 촬영한다.
- **수동 촬영:** 사용자가 원하는 순간에 직접 촬영할 수 있다.
- **앨범 보기:** 촬영한 사진을 애플리케이션 안에서 확인할 수 있다.

이를 통해 모델의 분류 결과를 단순히 확인하는 데서 끝내지 않고, 단체 사진 촬영이라는 실제 사용 상황에 연결했다.

## **4. 한계점 및 의의**

### **4.1. 한계점**

- 웹캠의 화질과 촬영 환경에 따라 얼굴과 눈 검출 성능이 달라져 카메라 성능에 민감했다.
- 안경을 착용한 사람의 눈 상태를 정확하게 인식하기 어려운 경우가 있었다.
- 웹캠보다 성능이 좋은 스마트폰 카메라 환경에서 충분히 테스트하지 못했다.
- 발표 자료에는 조명, 얼굴 각도, 사람 수에 따른 세부 성능 비교가 포함되지 않아 실제 환경에서의 일반화 성능을 정량적으로 확인하기 어렵다.

### **4.2. 의의**

- 모든 사람이 눈을 뜬 순간을 자동으로 포착해 여러 번 촬영하고 확인하는 시간을 줄일 수 있다.
- 눈 상태 분류 모델을 실제 촬영 흐름과 연결해 정확성과 사용 편의성을 함께 고려했다.
- 스마트폰 카메라뿐 아니라 포토 부스, 무인 촬영 기기 등 다양한 환경으로 확장할 수 있다.
- 기본 CNN, MobileNet, ResNet을 직접 비교하면서 경량 모델이 항상 더 적합한 것은 아니며, 실제 데이터와 목적에 맞춘 성능 검증이 중요하다는 점을 확인했다.


## **5. 마무리**

이 프로젝트에서는 여러 사람이 함께 있는 상황에서 각 사람의 눈 상태를 실시간으로 감지하고, 모두가 눈을 뜬 순간 자동으로 사진을 촬영하는 시스템을 구현했다. 초기에는 MobileNet 기반의 경량 모델을 중심으로 접근했지만, 모델 비교 실험에서는 ResNet이 테스트 정확도 97.78%로 가장 좋은 성능을 보였다.

이후에는 안경, 어두운 조명, 측면 얼굴처럼 실패가 자주 발생하는 조건을 별도로 수집해 평가하고, 스마트폰 환경에 맞게 모델을 경량화할 필요가 있다. 또한 사람 수와 촬영 거리에 따른 검출률과 전체 파이프라인의 처리 속도를 측정하면 실제 서비스로서의 완성도를 더 명확하게 검증할 수 있다.
